# Documentación de Timer for Friends

Paquete de contexto para Claude u otra IA. Empieza por `../CLAUDE.md`.

## Archivos

- `01_contexto/CONTEXTO_MAESTRO.md` — qué es, decisiones aprobadas, pendientes y mejoras.
- `02_diseno/FUNCIONALIDAD_ACTUAL.md` — rutas, flujos y modelo de datos de Firestore.
- `03_recursos/RECURSOS_Y_LICENCIAS.md` — recursos del proyecto, origen y licencia.
- `06_prompts_IA/REGLAS_DE_TRABAJO_IA.md` — reglas y ciclo de una mejora.
- `07_publicacion/PUBLICACION_GITHUB_PAGES.md` — cómo se despliega.
- `07_publicacion/CHECKLIST_PRUEBAS.md` — pruebas manuales antes de cada PR.

Las specs de mejoras viven en `../specs/` y se crean con `/spec`.

La numeración de carpetas sigue la del proyecto `pacmanlike-game`; las que no aplican aquí
(niveles, control de recursos) se omiten.
